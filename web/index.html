The page turns that many CLIFF into NEAR at the price you enter, then asks the 1Click API for three dry quotes of that same amount: AURORA on NEAR, AURORA on Ethereum, and USDC on Base. The end-to-end run, 8 November

Every number above is read from NEAR testnet when the page loads, through public view calls. Read grants uses public view calls. Wallet actions run only after you connect, review and confirm; Connect stores account selection in this browser; this desk does not request a function-call key.

The holder is paid after the lender: each unlock repays the loan first, fee included, then the rest goes to the holder.

Tokens enter only by token transfer to the contract and leave only by withdrawal, so what it owes should always equal what it holds.

Staking is refused in this contract, because its rewards would have no tokens behind them. The earlier demo contract still shows it.

Unlock days count from 1 January 1970, as NEAR block time does; the date beside each is the same day in UTC.

The Intents quotes are dry runs against the live 1Click API. The vesting contract stays on testnet. It is not deployed on mainnet: the escrow is unaudited, and a dry quote is the mainnet call this demo makes.

AURORA routes use the asset ids NEAR Intents publishes: the bridged AURORA token on NEAR, and the same token on Ethereum. Recipient addresses in the request are placeholders.

The 40% sale discount is the OFFX band for a term up to 12 months. This page does not read months remaining from the contract, so every slice quote uses that short-term band.

Source and tests: the public repository. Every transaction ID opens in the NEAR testnet explorer.
