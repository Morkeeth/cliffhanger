Cash out with NEAR Intents: a live quote, nothing sent

When a holder sells a slice or borrows, the cash can arrive as USDC on the chain they use. NEAR Intents has no testnet and CLIFF has no market, so this asks the real 1Click API for a dry-run quote on NEAR: no deposit address is created and nothing moves.

The end-to-end run, 8 November

Every number above is read from NEAR testnet when the page loads, through public view calls. Nothing is signed and nothing is stored.

The holder is paid after the lender: each unlock repays the loan first, fee included, then the rest goes to the holder.

Tokens enter only by token transfer to the contract and leave only by withdrawal, so what it owes should always equal what it holds.

Staking is refused in this contract, because its rewards would have no tokens behind them. The earlier demo contract still shows it.

Unlock days count from 1 January 1970, as NEAR block time does; the date beside each is the same day in UTC.

The Intents quote is a dry run against the live 1Click API on NEAR mainnet: no deposit address, no transfer, no key. Recipient addresses in the request are placeholders.

Source and tests: the public repository. Every transaction ID opens in the NEAR testnet explorer.
