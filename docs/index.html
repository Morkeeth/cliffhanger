The end-to-end run, 8 November

Every number above is read from NEAR testnet when the page loads, through public view calls. Nothing is signed and nothing is stored.

The holder is paid after the lender: each unlock repays the loan first, fee included, then the rest goes to the holder.

Tokens enter only by token transfer to the contract and leave only by withdrawal, so what it owes should always equal what it holds.

Staking is refused in this contract, because its rewards would have no tokens behind them. The earlier demo contract still shows it.

Unlock days count from 1 January 1970, as NEAR block time does; the date beside each is the same day in UTC.

A dry quote does not create a deposit. Prepare deposit does: 1Click returns an address. Sign in MyNearWallet reads your full-access key and a fresh block, then opens the wallet with the transfer. The page never broadcasts that transaction. The vesting contract stays on testnet.

AURORA routes use the asset ids NEAR Intents publishes. A CLIFF choice receives the bridged AURORA token on NEAR or the same token on Ethereum. An AURORA choice sends that NEAR-bridged token. Recipient addresses in the request are placeholders.

The sale discount is the OFFX band for the months still left: 40% up to 12 months, 50% for 13 to 24, 60% from 36. A live grant uses borrow.term_days from the contract. Between 25 and 35 months OFFX gives no band, so you enter a discount. The vesting contract is not on mainnet.

Source and tests: the public repository. Every transaction ID opens in the NEAR testnet explorer.
